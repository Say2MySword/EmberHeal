# EmberHeal

中文 | [English](README_EN.md)

**Emberveil 治疗框架**（HealBot 式）· 适用于 Emberveil 客户端（WoW 1.12.1 模拟 / Lua 5.1 API）· 当前版本 1.0.14

## 功能

- **团队 / 小队血条网格**：可拖拽、位置记忆，血条上白色名字与血量文字，双击复位
- **点击施法**：在「点击施法」页把 **左键 / 右键**（可组合 Shift / Ctrl / Alt）绑定到动作栏技能，点血条即施法（经动作槽施放，绑定自动轮换到下一个可用槽位）
- **驱散提示**：血条角标显示减益图标，按类型着色——魔法 / 疾病 / 中毒 / 诅咒各有字形
- **增益监视**：关键增益的剩余时间与消失提示，监视列表可在「监视」页配置
- **范围与仇恨**：目标超出施法范围时血条变暗；获得仇恨时边框高亮
- **悬停信息**：死亡 / 离线 / 超出距离 / 仇恨 / 减益类型一目了然
- **选项面板**：显示 / 点击施法 / 监视 三页，每个开关悬停都有说明文字
- **中英双语**：界面语言随客户端语言自动切换，无需手动设置
- **小地图按钮**：左键开关治疗框架；右键 / Shift+左键打开选项面板；拖动沿小地图环绕摆放
- 零第三方库，纯 Lua 5.1

## 安装

1. 下载 `EmberHeal-1.0.14.zip`（右侧 Releases）并解压
2. 把 `EmberHeal` 整个文件夹放进 `...\Emberveil\live\Azeroth\Interface\AddOns\`
3. 重登游戏（或 `/reload`）即生效

## 使用

- **开关框架**：点小地图按钮，或在选项面板里调整显示设置
- **绑定技能**：选项面板 →「点击施法」页 → 点击某一行，再点击动作栏上的技能即完成绑定；已绑定的行可一键清空
- **三个选项页**：
  - 显示：缩放、血量百分比、字号等显示开关
  - 点击施法：鼠标键与技能的绑定管理
  - 监视：增益 / 减益监视列表

## 已知限制

- 客户端引擎不会把 **鼠标中键 / 侧键** 事件派发给 Lua UI（引擎限制，插件侧无法绕过），因此点击施法目前支持左键 / 右键与修饰键组合。
